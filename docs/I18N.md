# Language packs

RapidGo selects its application language at startup from the first nonempty environment variable in this order: `LC_ALL`, `LC_MESSAGES`, `LANG`. An unsupported value in a higher priority variable does not cause a search of lower priority variables.

Packs use `language_REGION` names. Language is lowercase and region is uppercase; a hyphen also works as the separator. Encoding suffixes and modifiers are removed: `zh_CN.UTF-8`, `zh-cn.utf8@variant`, and `zh_CN@variant` all select `zh_CN`. Unset, invalid, `C`, `POSIX`, and unsupported locales select `en_US`.

The complete English pack is the default. A Simplified Chinese (`zh_CN`) pack translates common menus, help actions, dialogs, and messages; its remaining entries fall back to English. Missing or whitespace-only translations use the English entry. `i18n.Format` and `i18n.Errorf` use the English template if a translation changes argument indexes, conversion verbs, width/precision argument roles, or placeholder counts. This validation happens when a pack loads, so literal `%!` in runtime values is preserved. An unknown application key displays the selected pack’s generic `unknown_message`, falling back to English, without interpolating unused runtime arguments.

```sh
LC_ALL=zh_CN.UTF-8 rapidgo .
LC_ALL=en_US.UTF-8 rapidgo .
```

Language selection affects application messages, including CLI help and errors. Source text, paths, command arguments, program output, and messages received from Go, gopls, or the operating system retain their original contents. Core state values and protocol identifiers remain stable; their display labels are translated at the UI boundary.

## Add a pack

1. Copy `internal/i18n/packs/en_US.json` to a new `language_REGION.json` file in the same directory.
2. Keep the message keys and translate their values. Entries may be omitted during translation; they fall back to English. Keep intentional leading/trailing spaces in styled status and dialog labels.
3. Preserve keyboard bindings in shortcut entries and hints. For example, `F2`, `Ctrl+Q`, and the menu mnemonics `Alt+F/S/B/W/H` continue to invoke the same actions. Translate the surrounding action descriptions. Each menu has a `menu_<name>_mnemonic_index` entry: a zero-based grapheme index identifying the character to highlight, or `-1` to append the fixed mnemonic in parentheses. For example, `menu_file_mnemonic_index` is `0` for English `File` and `-1` for Chinese `文件`. Invalid indexes or indexes pointing at another character also append `(F)` rather than searching for an incidental letter.
4. Preserve printf placeholders and their types, including `%w` in wrapped errors. Arguments follow the English template's order. Use indexed arguments to reorder them: `msg_loaded_s_d_entries` receives the path as argument 1 and entry count as argument 2; a translation can use `%[2]d entries: %[1]s`. Literal percent signs in formatted messages use `%%`.
5. Run `make check`. Pack tests check message keys and each placeholder’s argument index, conversion verb, and width/precision role, and UI tests exercise wide characters, long labels, and narrow layouts.

Packs are embedded in the executable; rebuild RapidGo to include a new pack. No locale files need to be installed on the user's machine.

## Add an application message

Add a stable descriptive key and English value to `en_US.json`, then call `i18n.Text(key)` or `i18n.Format(key, arguments...)`. Keep paths and other runtime values in placeholders instead of assembling translated sentence fragments. Use `i18n.Errorf(key, ..., err)` with `%w` to preserve wrapped errors and apply the same translation fallback. Use `i18n.Error(key)` for sentinel errors; `errors.Is` compares their message keys, so both package-level sentinel variables and inline `i18n.Error(key)` targets work while their displayed text follows the selected language.

`internal/i18n` loads JSON through `fs.FS` and selects locales through an injected environment lookup. Neither depends on terminal widgets. The CLI selects a process catalog before launching background workers. Catalogs are immutable; tests can load isolated catalogs without changing the process language. Menu rendering calculates widths in terminal cells and help wraps grapheme clusters.
